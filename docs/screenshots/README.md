# Sonata terminal UI captures

These captures were taken from the running tcell application in a 90×30 tmux
terminal using a small local audio fixture (FLAC/MP3). PNGs are image renderings
of the captured terminal rows; matching `.txt` files retain raw terminal text.
Local fixture paths are redacted in committed captures.

- `01-main`: main menu and library summary
- `02-songs`: song list and selected track metadata
- `03-nowplaying`: active mpv playback, progress, mode, and volume
- `04-locked`: lock screen and unlock hint

This demonstrates the terminal UI, not final device rendering. RG34XX hardware
acceptance is still pending.
