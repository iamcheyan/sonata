所有主界面遵循四区：状态栏 / 左列表 / 右详情 / 提示栏。
图例：`>` 选中，`│` `─` 分隔线，`…` 截断。

锁屏只响应：播放/暂停、上一首、下一首、解锁组合。其余按键忽略且不提示。

## 9. 熄屏（Backlight Off）

```
（屏幕全黑；无任何输出）

- 音乐继续播放（mpv 进程独立）
- 任意键：仅唤醒，不触发动作
- 唤醒后再按：正常执行
```

终端实现：清屏 + 隐藏光标 + 不输出；若可写 backlight，同时关闭背光。
